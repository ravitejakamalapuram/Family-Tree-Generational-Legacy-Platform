# Kinfolk P0 clickable prototype\n\nOpen `index.html` directly in a modern browser. No dependencies or build step are required.\n\nThis is a design-validation artifact with fictional data. It is not a production application: no API, authentication, persistence, server-side authorization, media upload or production genealogy layout engine is included. Save/Continue actions are deliberately non-persistent.\n\nReview at desktop and mobile widths. Keyboard, screen-reader, regional-script and cross-browser QA remain pending. See `../P0_SCREEN_SPECIFICATIONS.md` for scope and acceptance criteria.\n
